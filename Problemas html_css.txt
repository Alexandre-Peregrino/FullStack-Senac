Problemas 
Problema 1: Link Quebrado 
Um aluno criou o seguinte código: 
<a hreff="https://www.google.com">Pesquisar</a> Perguntas: 
1.	Por que o link não funciona? 
Link Quebrado. O erro é o hreff (atributo inexistente). 
2.	Qual atributo está incorreto? 
<a href="">
3.	Reescreva o código corretamente. 
<a href="https://www.google.com">Pesquisar</a>

Problema 2: Imagem Não Aparece 
Observe o código: 
<img src="foto_perfil.j A imagem não é exibida. 
Perguntas: 
1.	O que pode estar causando o problema? 
O problema é o atributo src mal fechado: src="foto_perfil.j não tem aspas de fechamento nem extensão completa, então o navegador não encontra o arquivo.
2.	Qual a função do atributo src?
O src serve para localizar o arquivo da imagem.Acrescente um atributo alt adequado
<img src="foto_perfil.jpeg" alt="Foto de perfil">
Problema 3: Formulário Incompleto 
<label>Nome:</label> 
<input type="text"> Perguntas: 
1.	O código funciona? 
não
2.	O que falta para associar corretamente o label ao input? 
O correto é usar for no <label> apontando para o id do <input> 
3.	Corrija o código. 

<label for="nome">Nome:</label>
<input type="text" id="nome" name="nome">

Problema 4: Erro de CSS h1 color: blue; 
font-size: 20px; 
Perguntas: 
1.	O que está errado? 
Faltam as chaves {} 
2.	Reescreva a sintaxe corretamente. 
h1 {
color: blue; 
font-size: 20px; 
}

Desafio 3: Classe e ID 
Crie: 
●	Um parágrafo usando uma classe chamada .destaque 
●	Um título usando um id chamado #titulo 
Aplique estilos diferentes para cada um.
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Classe e ID</title>
  <style>
    /* Seletor de classe: aplicado com . */
    .destaque {
      color: white;
      background-color: orange;
      padding: 10px;
      font-weight: bold;
    }
    /* Seletor de id: aplicado com # */
    #titulo {
      color: darkblue;
      text-align: center;
      font-size: 32px;
    }
  </style>
</head>
<body>
  <h1 id="titulo">Meu Título Principal</h1>
  <p class="destaque">Este parágrafo usa a classe "destaque".</p>
</body>
</html>

<html lang="pt-BR">
<head>
  <meta charset="UTF-8">

      font-family: Arial, sans-serif;
